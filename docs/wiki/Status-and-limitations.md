# Status and limitations

Version 1.0.0 provides macOS ARM64 and Windows x64 / ARM64 packages. The macOS release is ad-hoc signed and is not Apple-notarized; Windows releases are not Authenticode-signed. The Windows x64 package has been built and run on Windows, with native UI previews and checks for menu repainting, action saving, profile switching, and shortcut persistence. Physical receiver behavior and Windows dictation still need live acceptance testing. The user has verified macOS microphone recording/playback and remote-triggered ChatGPT dictation; the latest ChatGPT shortcut change has not been retested live. No new hardware or audio-capture test was performed for this release. Windows ARM64 is cross-built and has not been run on ARM64 hardware by CI.

Windows custom actions run alongside native button actions. On macOS, multiple remotes require distinct receiver hardware IDs. Remote cursor settings adjust native speed and acceleration only; physical calibration is not supported.
