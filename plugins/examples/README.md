# Agent-ready plugin starters

Copy `device/` or `app/` to a separate project folder before customizing it. Each starter includes a portable `AGENTS.md`, API guide, schema snapshot, draft manifest, README, and acceptance record.

Open the copied folder in your coding agent and ask it to read `AGENTS.md` first. See `docs/PLUGIN-AUTHORING.md` in the JustVibe Remote repository for copyable prompts and a workflow that keeps core updates independent.

These are templates with placeholders, not verified integrations. Do not install an unmodified starter. Community plugins belong in the user's external plugin directory, not in this source directory or `plugins/bundled/`.
